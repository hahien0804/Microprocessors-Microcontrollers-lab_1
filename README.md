# Microprocessors-Microcontrollers-lab_1
## Overview
This repository contains the source code and Proteus simulation files for Lab 1. The lab focuses on GPIO manipulation on the STM32F103C6 microcontroller to create various LED animations, traffic lights, and an analog clock simulation.

## Repository Structure
* `/Proteus`: Contains the `.pdsprj` simulation files.
* `/STM32_Code`: Contains the STM32CubeIDE project source code and `.ioc` configuration files.
* `/Hex_Files`: Pre-compiled `.hex` files for direct loading into the Proteus STM32 component.
